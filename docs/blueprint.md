# **App Name**: Psicóloga Isabela

## Core Features:

- Home: Página inicial com uma mensagem acolhedora e chamadas para ação.
- Sobre Isabela: Página 'Sobre' detalhando a formação e a abordagem de Isabela.
- Serviços / Abordagem: Página de 'Serviços' descrevendo as especialidades terapêuticas.
- Blog: Página de 'Blog' com um layout limpo para artigos.
- Contato: Página de 'Contato' com um formulário simples e informações de contato claras.
- Splash Animation: Animação de abertura com um círculo rosa pastel que se expande para revelar o conteúdo do site.

## Style Guidelines:

- Cor primária: Rosa pastel dessaturado (#E1BCC0) para detalhes e destaques importantes.
- Base: Fundo off-white quente e texturizado (#F9F7F5) para criar uma sensação acolhedora.
- Contraste: Cinza-chumbo profundo (#3D405B) para textos principais e títulos, transmitindo estabilidade.
- Cor neutra secundária: Bege-acinzentado ou 'greige' (#BDB2A7) para cards e seções secundárias.
- Fonte dos títulos: 'Playfair Display', uma fonte serifada moderna para os títulos, transmitindo autoridade. Observação: atualmente, apenas as fontes do Google são compatíveis.
- Fonte do corpo do texto: 'Inter', uma fonte sans-serif limpa para uma leitura confortável. Observação: atualmente, apenas as fontes do Google são compatíveis.
- Layout assimétrico e dinâmico com espaços em branco generosos e elementos sobrepostos para criar profundidade.
- Animação de abertura fluida e relaxante com um círculo rosa pastel que se expande para revelar o conteúdo.
