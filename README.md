## 🌎 English Version:

**Professional Platform for Psychologist Isabela Frotté**

This project showcases a strategic approach to web development, delivering a high-performance digital platform for a clinical psychologist. It combines the speed of a static site with the dynamism of a client-managed blog, solving a common business challenge for independent professionals.

➡️ Live Demo: psicologaisabelafrotte.com.br

### The Challenge

The client needed more than a website; she needed an asset that could grow with her practice. The key challenge was to provide a system where she could autonomously publish SEO-optimized content (a blog) without incurring server costs or requiring technical intervention for each new post.

### ✨ The Solution & Key Features

The solution was to build a decoupled platform using a modern, strategic stack focused on performance, SEO, and client autonomy.

Decoupled Architecture: The front-end was built with Next.js (App Router) and connected via API to a Sanity.io Headless CMS. This decouples the content from the code, giving the client full control over her own content strategy.

Performance-First with ISR: I implemented an Incremental Static Regeneration (ISR) strategy. The site is served as static files for maximum speed, while new blog posts published in the CMS trigger automatic, on-demand rebuilds in the background. This delivers the performance of a static site with the flexibility of a dynamic one.

### Complete SEO Suite:

Dynamic Sitemap (sitemap.ts): Automatically generates and updates the sitemap as new content is added.

Structured Data (JSON-LD): Implemented to provide Google with rich context about the professional's practice, improving search result appearance.

Advanced Metadata: Complete Open Graph and Twitter tags for professional and engaging link sharing on social media.

Styling: A custom, responsive, and consistent design system was rapidly developed using Tailwind CSS.

Deployment: A seamless CI/CD (Continuous Integration/Continuous Deployment) pipeline was configured on Netlify, where every git push to the main branch automatically triggers a new build and deployment.

## 💡 Key Results & Impact

For the Client: Delivered 100% content autonomy, empowering her to manage her own SEO strategy without technical dependency.

For the Business: Created a highly scalable, zero-cost hosting solution that combines elite performance with dynamic capabilities, solving a critical business need for independent professionals.

**Plataforma Profissional para a Psicóloga Isabela Frotté**

Este projeto demonstra uma abordagem estratégica ao desenvolvimento web, entregando uma plataforma digital de alta performance para uma psicóloga clínica. Ele combina a velocidade de um site estático com o dinamismo de um blog gerido pela cliente, resolvendo um desafio de negócio comum para profissionais independentes.

➡️ Demonstração ao Vivo: psicologaisabelafrotte.com.br

### O Desafio

A cliente precisava de mais do que um site; ela precisava de um ativo que pudesse crescer com a sua prática. O desafio principal era fornecer um sistema onde ela pudesse publicar conteúdo otimizado para SEO (um blog) de forma autónoma, sem incorrer em custos de servidor ou necessitar de intervenção técnica para cada novo post.

### ✨ A Solução e Funcionalidades-Chave

A solução foi construir uma plataforma desacoplada, utilizando uma stack moderna e estratégica, focada em performance, SEO e autonomia da cliente.

Arquitetura Desacoplada: O front-end foi construído com Next.js (App Router) e conectado via API a um Headless CMS (Sanity.io). Isto desacopla o conteúdo do código, dando à cliente controlo total sobre a sua própria estratégia de conteúdo.

Performance em Primeiro Lugar com ISR: Implementei uma estratégia de Regeneração Estática Incremental (ISR). O site é servido como ficheiros estáticos para velocidade máxima, enquanto novos posts publicados no CMS acionam reconstruções automáticas e sob demanda em segundo plano. Isto oferece a performance de um site estático com a flexibilidade de um dinâmico.

### Suite Completa de SEO:

Sitemap Dinâmico (sitemap.ts): Gera e atualiza automaticamente o sitemap à medida que novo conteúdo é adicionado.

Dados Estruturados (JSON-LD): Implementado para fornecer ao Google um contexto rico sobre a prática da profissional, melhorando a aparência nos resultados de pesquisa.

Metadados Avançados: Tags Open Graph e Twitter completas para uma partilha de links profissional e apelativa nas redes sociais.

Estilização: Um sistema de design personalizado, responsivo e consistente foi desenvolvido rapidamente utilizando Tailwind CSS.

Deployment: Um pipeline de CI/CD (Integração Contínua/Entrega Contínua) foi configurado na Netlify, onde cada git push para o ramo principal aciona automaticamente um novo build e deploy.
